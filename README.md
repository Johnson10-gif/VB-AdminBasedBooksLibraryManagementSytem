# Library Management System with Admin Controls

## Overview
A Library Management System (LMS) is an application that facilitates the management of library functions. It streamlines the processes of lending and returning books, tracking inventory, and managing user accounts. This specific design includes features that empower administrators to have control over various functionalities.

## Features

### Admin Controls
- **User Management**: Administrators can add, update, or delete user accounts, ensuring that library access is properly managed.
- **Book Management**: Admins can add new books, update information about existing books, and remove books from the library inventory as needed.
- **Transaction Monitoring**: Admins can view transactional history, which includes lending records and returned dates, aiding in effective inventory tracking.
- **Reports Generation**: Admins can generate reports on library usage, popular books, and user activity to assess library performance and make informed decisions.

### User Features
- **Search Functionality**: Users can easily search for books by title, author, or category.
- **Book Reservation**: Users can reserve books that are currently checked out, allowing them to be notified when these books become available.
- **Account Management**: Users can view their current loans, return due dates, and manage their profiles.

## Technologies Used
- **Front-end**: HTML, CSS, JavaScript
- **Back-end**: Node.js, Express
- **Database**: MongoDB
- **Version Control**: Git

## Installation Instructions
1. Clone the repository: `git clone https://github.com/Johnson10-gif/VB-AdminBasedBooksLibraryManagementSytem.git`
2. Navigate to the project directory: `cd VB-AdminBasedBooksLibraryManagementSytem`
3. Install dependencies: `npm install`
4. Start the application: `npm start`

## Usage
Once the application is running, navigate to `http://localhost:3000` in your web browser to access the Library Management System.
